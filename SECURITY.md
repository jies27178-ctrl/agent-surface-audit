# Security policy

## Reporting a vulnerability

Please do not publish suspected vulnerabilities or live credentials in public issues. Use GitHub's private vulnerability reporting feature when available, or contact the repository owner through GitHub with a minimal reproduction and the affected version or commit.

## Scope

The scanner must not execute scanned content, transmit scanned content, or expose a matched credential in output. Changes that affect scanning scope, redaction, command execution, filesystem traversal, or dependencies require focused review and tests.
